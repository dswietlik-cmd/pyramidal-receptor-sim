# Release policy

## v0.9.x — pre-publication development

The public v0.9.x series is intended for transparency, testing, and reproducible development while the associated manuscript is being prepared. Scientific parameters, interfaces, simulations, and analyses may still change.

When reporting results from a v0.9.x checkout, record the exact Git commit hash or tag.

## v1.0.0 — manuscript-associated frozen release

Version 1.0.0 will be created only after the model, simulation protocol, concentration grids, statistical analysis, figures, and manuscript Results are frozen. That release will be archived in Zenodo (or another long-term repository) and assigned a DOI for citation in the manuscript.
